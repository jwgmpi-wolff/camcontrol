Step 1 — Capture Google token from YI app
YI uses Google Sign-In with their own private OAuth client. Capture the token from the running app:
  1. Install HTTP Toolkit on your Android phone (free, no root)
  2. Open HTTP Toolkit → Android (via ADB) or Manual setup
  3. Open YI Home app → tap sign in with Google
  4. In HTTP Toolkit, search requests for id_token
  5. Copy the full id_token value (starts with eyJ)
Alternative: use PCAPdroid or mitmproxy on the same WiFi to capture the token.
